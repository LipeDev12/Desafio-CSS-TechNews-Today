# 💻 TechInfo - Portal de Informações sobre Tecnologia

> Projeto desenvolvido como resposta ao desafio proposto pelo **Professor Denani** para criar um site informativo sobre o mundo da tecnologia.

---

## 📌 Sobre o Projeto

Este site foi criado com o objetivo de apresentar conceitos, novidades e informações relevantes do universo tecnológico. A proposta surgiu a partir de um desafio acadêmico do **Professor Denani**, servindo como prática prática para a consolidação de conhecimentos em desenvolvimento web front-end.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi desenvolvido exclusivamente utilizando tecnologias fundamentais da web:

- **HTML5**: Estruturação semântica do conteúdo e das páginas do site.
- **CSS3**: Estilização visual, esquemas de cores, tipografia e layout responsivo.

---

## ✨ Funcionalidades

- 📰 **Conteúdo Informativo:** Seções organizadas sobre temas do mercado de tecnologia.
- 🎨 **Design Clean:** Layout intuitivo focado na experiência de leitura do usuário.
- 📱 **Responsividade:** Adaptação para diferentes tamanhos de tela (desktop e mobile).
- 🧭 **Navegação Fluida:** Links e menus estruturados para facilitar o acesso.
